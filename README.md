## What I do

**Turn a manual process into a system.** Someone is copying data between four tools every Monday. I map it, rebuild it in n8n, Make or Python, and hand back something that runs itself and tells you when it breaks.

**Build the internal tool nobody has time to build.** Application portals, trackers, dashboards, review workflows. The thing that is currently a shared spreadsheet with eleven tabs and one person who understands it.

**Make the numbers visible.** Support metrics, pipeline reporting, cohort and performance analysis. Usually in SQL and Python, surfaced in Power BI, Tableau or a plain HTML dashboard that anyone can open.

**Put LLMs where they pay off.** Knowledge-base assistants, drafting and triage steps inside existing workflows, evaluation loops. I use Claude and GPT daily and I am opinionated about where they belong and where they waste money.
